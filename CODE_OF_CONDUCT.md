# Code of conduct

ParkWhere follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment and personal attacks aren't accepted in issues, pull requests or any other project space.

To report a problem, use GitHub's **Report a vulnerability** form on the Security tab if it needs to stay private, or contact the maintainer through their GitHub profile. Reports are handled confidentially.
